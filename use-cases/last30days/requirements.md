# Requirements

**OpenClaw setup is the only requirement.**

You need a working OpenClaw with the ability to install skills and run scheduled tasks. Once
OpenClaw is set up, it handles installing the `last30days` skill and scheduling the morning
brief for you — just give it the prompts in [`INSTALL.md`](INSTALL.md).

> Some sources (X, YouTube, TikTok, etc.) can be unlocked with your own API keys, but they are
> **optional**. Reddit, Hacker News, Polymarket and GitHub work out of the box with no keys, so
> you can get a useful morning brief without configuring anything extra. If you want the optional
> sources later, just ask OpenClaw and it will walk you through the setup wizard.
