# Agents

Agent definitions grouped by role:

- **`orchestrator/`** — coordinator agents that delegate and synthesize.
- **`gateway/`** — OpenClaw Gateway entry points that validate and route requests.
- **`workers/`** — task-focused agents that do the actual work.

Each file is `<name>.agent.md`. Start from
[`../.templates/agent.template.md`](../.templates/agent.template.md) and follow
[`../docs/CONVENTIONS.md`](../docs/CONVENTIONS.md).
